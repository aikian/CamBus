# CamBus Roadmap

현재 릴리스: **1.3.0**

## 1.3.0 완료

- 길찾기 출발 시간 지정
- 노선 코드 공유 정류장(서문/1과학관/중앙도서관) 자동 환승 인식과 환승 경로 후보
- 정류장 이름 지하철식 단축, 음악관·기계관 중복 정차점 통합
- 테스트 전용 시간 가속 모드(`?test=1`)

## 1.2.0 완료

- 정류장 좌표 편집과 별도 노선 경유점/실측시간 편집
- 앱에서 로컬 고정 노선 사용, 순환 길찾기 랩어라운드 수정
- 실제 광고 전환용 서버 설정과 운영 계획
- 모바일 핵심 조작 영역/접근성/오프라인 폴백 개선
- Picks 예약·만료 필드와 링크 검사
- 데이터/API 회귀 테스트

## 다음 우선순위

### 운영 투입 전

- 2노선 5번(아트센터) 단축 이름 최종 확정 (현재는 임시 이름)
- 운영 도메인·HTTPS·개인정보처리방침 준비
- Ezoic/MCM 승인, CMP/header 스크립트, placement, ads.txt 연결
- 실제 버스 운행으로 구간시간 표본 입력
- iOS Safari/Android Chrome 실기기 회귀 테스트
- Picks 링크 검사 정기 실행과 콘텐츠 만료일 입력
- OpenStreetMap 타일/라우팅 운영 제공자 또는 자체 인프라 결정

### 2.0.0 후보

- 데이터베이스 기반 운영
- 별도 백엔드 배포
- 운영 통계/모니터링
- 네이티브 또는 Capacitor 앱 전환 검토
