# CHANGELOG

모든 주요 변경사항은 이 파일에 기록합니다.

버전 규칙은 Semantic Versioning(`MAJOR.MINOR.PATCH`)을 사용합니다.

## [1.7.0] - 2026-08-30

### Added

- **캠퍼스 밖 출발 길찾기 — 지하철 + 교내버스 연계.** 출발지가 캠퍼스에서 1.5km 넘게
  떨어져 있으면 지하철로 영남대역까지 온 뒤 교내버스로 목적지까지 잇는 경로를 제안합니다.
  노선 선(폴리라인)은 그리지 않고 **어디서 타고 어디서 내리는지**만 안내합니다
  - 예) 대구 중구 → 기계관 = 51분
    `중앙로역 도보 130m → 1호선 중앙로→반월당 → 2호선 반월당→영남대 → 2노선 노천강당→기계관`
- `data/subway-daegu.json` — 대구 도시철도 1·2·3호선 94개 역, 환승역(반월당·청라언덕·명덕).
  OpenStreetMap 노선 관계에서 생성했고 API 키가 필요 없습니다
- `subway-router.js` — 역 그래프 다익스트라 경로 탐색(환승 4분 가정).
  역간 소요시간은 표정속도 30km/h + 정차 20초 추정치입니다
- 요약 막대 색 구분: **지하철 검정 · 시내버스 회색**, 교내 노선은 기존 노선 색 유지

### Fixed

- 캠퍼스 밖에서 출발하면 "18km 도보" 같은 비현실적 후보가 결과에 섞이던 문제 —
  도보 전용 3km, 정류장 접근 도보 합계 2.5km 상한을 넘는 경로는 제외
- 새 경로 유형에서 `drawPlan()`이 `walkIn.geometry` 접근으로 크래시하던 문제

## [1.6.0] - 2026-08-30

### Added

- **카카오맵식 경로 요약 UI** — 카드 상단에 `도보 10분 › 2노선 3분` 한 줄 파이프라인과,
  구간 소요시간 비율대로 폭을 나눈 막대를 표시. 도보는 점선, 버스는 노선 색.
  기존 단계별 목록은 `상세 경로`로 접어 기본은 요약만 보이게 정리
- 요약 아래 메타를 `과학관 승차 · 기계관 하차 · 13:00 출발편`으로 바꿔 어디서 타고 내리는지
  펼치지 않아도 보이게 함
- **시내버스(TAGO) 서버 프록시** `transit-api.js` + `/api/city-bus/{config,stops,arrivals}`
  - 인증키는 `CAMBUS_TAGO_KEY` 환경변수로만 읽습니다. PWA라 클라이언트 파일은 누구나
    열어볼 수 있어 키를 넣으면 그대로 유출되므로, 브라우저는 프록시만 호출합니다
  - 도착정보 20초 / 정류소 목록 6시간 캐시로 일 10,000건 한도 절약
  - 영남대 앞 정류장은 경산(37100)·대구(22) 두 도시코드가 함께 서비스함을 확인

### Verified

- 속도 기반 승·하차 알림(기존 구현)을 GPS 좌표열 주입으로 검증 — 승차 정류장 도착 →
  **탑승 자동 감지** → 하차 예고(속도 기반 ETA) → 곧 하차까지 전 단계 정상 동작

## [1.5.0] - 2026-08-30

### Added

- **홈 화면 추가(PWA 설치) 유도** — 하단 배너와 `install.js`
  - 안드로이드·데스크톱 Chromium: `beforeinstallprompt`를 가로채 두었다가 `추가` 버튼 한 번으로
    네이티브 설치창 실행. 브라우저 기본 미니 배너는 억제
  - iOS Safari: 애플이 프로그램 설치 API를 제공하지 않아 `공유 → 홈 화면에 추가` 2단계 안내
    다이얼로그로 대체. 인앱 브라우저(카카오·인스타 등)에서는 추가가 불가능하므로 배너를 띄우지 않음
  - 이미 설치해 실행 중이거나(`display-mode: standalone`) 사용자가 닫은 경우 14일간 재노출 안 함
- PWA 아이콘 PNG 생성 — `icon-192/512.png`, maskable 2종, `apple-touch-icon.png`(180)

### Fixed

- **설치가 아예 불가능하던 문제.** manifest에 SVG 아이콘만 있어 Chrome의 설치 조건(래스터
  PNG 192·512)을 못 채웠고, 그 결과 `beforeinstallprompt`가 발생하지 않았습니다.
  Chrome `Page.getInstallabilityErrors` 결과가 이제 **차단 사유 없음**입니다
- iOS용 `apple-touch-icon` 링크 누락 — 홈 화면에 아이콘 대신 페이지 스크린샷이 들어가던 문제
- 스모크 테스트가 임시 프로필 삭제 실패(윈도우 EPERM)로 통과 결과를 덮어쓰던 문제

## [1.4.0] - 2026-08-30

### Fixed

- **길찾기가 엉뚱한 정류장에 내리라고 하던 근본 원인 수정.** 순환버스는 한 바퀴 도는 동안
  같은 역에 두 번 정차합니다(음악관·기계관·이도·거울못·사범대). 지도 핀을 합치려고 정류장
  항목 자체를 삭제했더니, 경로 계산에서 "두 번째 정차"가 사라져 버스가 그 역을 딱 한 번만
  선다고 믿게 됐습니다.
  - 증상: `과학관 → 기계관`이 서문(5분 정차)을 거쳐 **889초** 타는 걸로 계산돼, 대신 이도에서
    내려 걸어가라고 안내. 실제로는 이도 다음이 바로 기계관(약 2분)
  - 조치: 공지 원문의 정차 순서를 복구(1노선 11회 · 2노선 12회). 삭제됐던 정차 좌표가 전부
    경유점에 남아 있어 그대로 되살렸고, 지도에는 여전히 역당 핀 하나만 그립니다
    (표시용 병합과 경로 계산용 정차를 분리)
  - 결과: `과학관 → 기계관` 5분(버스 3분, 도보 0m), `중도 → 이도`·`천마관 → 음악관`도
    목적지 정류장에 바로 하차
- 승·하차 후보를 직선거리 가까운 3개로 미리 자르던 로직 제거. 같은 역을 두 번 서는 노선에서
  정작 가까운 쪽 정차가 후보에서 빠질 수 있었습니다. 이제 모든 조합을 예비 점수로 평가한 뒤
  상위 5개만 실제 보행 경로를 구해 최종 선택합니다(예비 점수는 직선거리라 도보를 과소평가)

## [1.3.1] - 2026-08-30

### Fixed

- 예상 버스 마커가 노선에서 벗어나 보이던 문제 (원인 3가지)
  1. 겹침 구간에서 선만 좌우로 벌어지고 버스는 원래 중심선 좌표를 써서 어긋남
  2. 버스 위치를 시간 비율로 계산해 거리 기준으로 그려진 선에 대입 (정차 중에는 정류장 원좌표로 튐)
  3. 5초 간격 표본 사이를 **직선 보간**해서, 배속을 올리면 한 번에 크게 건너뛰며 건물·코너를 가로지름
  → 위치를 노선 전체 거리 대비 진행 비율로 구하고, `renderRoute()`가 실제로 그린 좌표 위에서
  매 프레임(`requestAnimationFrame`) 다시 계산하도록 변경. 구조적으로 선을 벗어날 수 없음
  (측정: 30배속 실시간 14프레임 최대 이탈 0.85px, 4개 축척 정적 스윕 1,608표본 최대 0.98px, 이전 21.1px)
- 폴리라인 누적거리 표를 `WeakMap`에 캐시하고 이분탐색으로 조회 — 매 프레임 재계산 비용 제거
- 확대·축소나 노선 토글 직후 버스 위치가 한 틱 늦게 갱신되던 문제
- 정류장 좌표를 나중에 편집기로 옮겨도 환승 거리 계산이 옛 좌표를 쓰던 문제

### Changed

- 1노선 빨강(#e63946) / 2노선 파랑(#3478f6) / 환승 보라로 색상 통일 (지도·범례·배지·편집기)
- 예상 버스와 공유 위치 마커를 노선 색 원형 점(흰 테두리, 안에 호선 번호)으로 변경
- 정류장 마커를 번호 대신 짧은 역 이름 알약으로 변경, 좌표가 겹치는 환승역은 마커 하나로 통합
- 순환 종점(기점 복귀 지점)은 시작 정류장과 같은 지점이므로 지도에 중복 표시하지 않음
- 정류장 이름 정리: 중앙도서관→중도, 과학도서관→이도, 1과학관→과학관
- 2노선 거울못(F22/G01)·이도(F27/G07) 왕복 중복 정차점을 각각 하나로 통합
  (도로 경유점은 이어붙여 보존, OSRM 재계산 없음)
- 보행 라우팅 서버 응답이 없을 때 직선거리 기준 추정치로 폴백해 예상 시간이 항상 표시됨
- 로컬(`localhost`/`127.0.0.1`) 접속은 파라미터 없이도 테스트 시간 가속이 켜짐 (`?test=0`으로 해제)

## [1.3.0] - 2026-08-29

### Added

- 길찾기 출발 시간 지정(`지금 출발` / `시간 지정`) — 고른 시각 기준으로 배차·대기·환승을 다시 계산

- 정류장 팝업의 환승 배지(🔄) — 같은 지점/도보 환승 여부와 노선을 바로 표시

- `?test=1&simTime=HH:MM&simSpeed=N` 테스트 전용 시간 가속 모드 — 실제 시각과 무관하게 지정한 시각부터 N배속으로 흘러 배차/버스 마커/정류장 ETA를 항상 볼 수 있음. 실제 서비스 화면에는 사용하지 않음
- `route-utils.js`에 `buildTransferStations`/`transferWalkSeconds` 순수 함수와 테스트 추가

### Changed

- 학생지원팀 공지(2026학년도 2학기 순환버스 증편) 원문을 다시 대조해 배차표·정류장 수·서문 5분 정차가 정확히 일치함을 확인
- 정류장 편집기/노선 데이터가 새 정류장 수(1노선 10개, 2노선 11개)에 맞춰 재계산됨
